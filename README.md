# Noodoe Statement Generator

A React application that converts Noodoe charging session data into professional transaction statements.

## Features

- Upload CSV or Excel files from Noodoe charging sessions
- Generate formatted transaction reports with totals and summaries
- Export statements as PDF or Excel files
- Automatic calculation of taxes, fees, and net payouts
- Responsive design for desktop and mobile

## Tech Stack

- React + TypeScript
- Tailwind CSS
- Papa Parse (CSV processing)
- SheetJS (Excel processing)
- jsPDF + html2canvas (PDF generation)
- Lucide React (icons)
